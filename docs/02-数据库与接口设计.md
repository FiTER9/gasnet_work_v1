# 数据库与后端接口设计

## 数据库

核心表：`users` 用户与角色；`network_models` 模型和阀门 JSON 配置；`gas_data` 每批次、每支路的 P/Q/U 与风险；`alarm` 报警类型、等级、描述、处理状态和处置留痕；`control_results` 控制器评价指标。ORM 启动时自动建表，MySQL 核心 DDL 见 `database/mysql.sql`。

## REST 接口

| 方法 | 路径 | 功能 |
|---|---|---|
| POST | `/api/auth/token` | 登录并取得 JWT |
| GET | `/api/users/me` | 当前用户信息 |
| GET/POST | `/api/models` | 查询/创建模型 |
| POST | `/api/simulation/command` | start/pause/resume/stop |
| GET | `/api/simulation/state` | 当前快照 |
| WS | `/ws/monitor?token=` | 秒级 P/Q/U 与风险推送 |
| GET | `/api/history` | 历史运行数据 |
| GET | `/api/alarms` | 报警列表 |
| PATCH | `/api/alarms/{id}/handle` | 报警确认处理 |
| GET | `/api/analysis/controllers` | PID/DRL 指标 |
| GET | `/api/health` | 健康检查 |

完整可执行接口契约由启动后的 `/docs` 提供。
