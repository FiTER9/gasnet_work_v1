# 软件使用说明书（软著版框架）

## 1. 软件概述

软件名称、版本、适用场景、术语、运行限制和安全声明。

## 2. 运行环境与安装

Windows 10/11 或 Linux；Python 3.11+；推荐 4 核 CPU、8 GB 内存；生产使用 MySQL 8.0+；高保真仿真需要 MATLAB/Simulink 及相应许可证。按 README 创建环境、安装依赖并启动。

## 3. 登录

打开系统地址，输入账号密码。演示账号为 `admin / Admin@123`，首次生产部署必须修改密码与 `SECRET_KEY`。

## 4. 模型管理

进入“模型管理”，填写模型名称、管径、管长、入口压力、额定流量和阀门配置并保存。参数必须采用项目统一量纲。

## 5. 仿真运行与监测

在“实时监控”点击开始；暂停冻结动态推进，继续恢复，停止结束运行。页面显示入口压力、总流量、仿真步数、拓扑节点状态及 60 秒趋势。

## 6. 风险与报警

绿色、黄色、红色分别对应 Level 0、1、2。出现报警后进入“报警管理”核对设备和描述，依据现场规程处置后点击“确认处理”。软件确认不等同于现场安全复位。

## 7. 历史与结果分析

历史页面查询逐支路记录；结果分析页对比 PID/DRL 四类指标。正式试验须保证工况、采样周期和评价窗口一致。

## 8. 运维与故障处理

检查 `/api/health`、服务日志、数据库连接和 MATLAB 许可证。定期备份数据库、轮换密钥、清理历史数据并校验时钟同步。

## 9. 软著截图建议

登录页、实时监控大屏、模型管理页、报警管理页、历史数据页、PID/DRL 对比页、Swagger 接口页各一张；截图中使用仿真数据并遮蔽真实生产信息。
