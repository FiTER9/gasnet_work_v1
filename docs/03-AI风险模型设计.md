# AI 安全风险预测模型设计

V1.0 使用混合智能基线。特征为每支路 `[压力P, 流量Q, 阀位U]`，并派生压力偏差、阀位条件下的期望流量偏差及流量/阀位耦合偏差。加权异常分数映射为 Level 0 正常、Level 1 注意、Level 2 危险；压力、流量危险边界拥有最高优先级。

工程升级时，以 `gas_data` 的时间窗构造 `[batch, time, 9]` 张量，用 LSTM 预测未来压力和异常概率。标签由经确认报警及专家复核生成，按仿真批次划分训练/验证/测试集，防止时间泄漏。评价指标采用宏平均 F1、Level 2 召回率、误报率和提前预警时间；模型版本、数据版本、阈值与指标必须登记。上线采用影子运行，只有通过不同负荷与故障注入测试后才启用提示，硬安全边界始终保留。

当前实现位于 `app/risk.py`，不依赖训练数据即可复现实验；这也是后续随机森林、SVM 或 LSTM 的统一推理接口。
