# 天然气管网智能安全监测与仿真平台 V1.0

## 软件简介

本软件面向天然气输配系统的仿真验证与安全生产辅助分析，将管网动态仿真、运行数据采集、实时态势可视化、智能风险识别、报警闭环和控制策略评价集成于统一平台。系统支持三支路示范管网，也可扩展至任意支路拓扑；在未部署 MATLAB 时可使用内置动态模型完成演示。

## 总体架构

```text
用户/浏览器
    │ HTTPS + WebSocket
GUI 监控与管理界面
    │
FastAPI 业务逻辑层 ── 用户/模型/仿真/报警/历史/结果 API
    │                    │
智能分析层              数据持久层
规则安全边界+异常评分    MySQL（演示可用 SQLite）
    │
仿真适配层
内置动态模型 / MATLAB Engine + Simulink
```

模块边界为：表现层仅负责交互和绘图；业务层维护权限、状态机与流程；分析层输入 `[P,Q,U]` 输出风险等级及解释；仿真层统一输出时间戳、压力、流量和阀位；数据层保存审计数据。

## 主要功能

1. 用户身份认证及用户信息查询。
2. 管径、管长、入口压力、额定流量及阀门参数建模。
3. 仿真开始、暂停、继续、停止与实时数据流。
4. 管网拓扑、关键指标及 P/Q/U 趋势监测。
5. Level 0/1/2 智能风险识别和原因解释。
6. 报警产生、查询、确认和处理人留痕。
7. 运行数据、报警数据及仿真批次历史管理。
8. PID 与 DRL 的压力误差、流量误差、阀门动作和稳定时间对比。

## 技术特点与创新点

- 双仿真适配：内置模型便于部署，Simulink 保留高保真工程模型。
- 安全混合智能：硬边界拥有安全否决权，耦合异常分数识别单变量阈值难以发现的偏离。
- WebSocket 秒级推送，实现仿真、分析、显示与入库的闭环。
- 风险结果包含等级、类型、分数与自然语言解释，便于值守人员复核。
- 同工况控制策略指标模型，支持 PID/DRL 可量化评价。

## 软件操作流程

登录 → 选择/创建管网模型 → 配置阀门 → 启动仿真 → 实时查看拓扑和曲线 → 系统计算风险 → 超阈值生成报警 → 操作员确认处置 → 查询历史 → 对比控制策略 → 导出/归档结果。

## 非功能设计

密码使用 bcrypt 散列，接口使用 JWT 鉴权；输入由 Pydantic 校验；数据库索引覆盖时间、批次和状态查询。生产部署应使用 HTTPS、短期令牌、独立密钥、角色权限、数据库备份及审计日志。系统分析结论属于辅助决策，不直接替代安全联锁。
